# Agnostify

We build plug-and-play AI tools for businesses, so owners can put AI to work day to day without having to figure it out themselves. We also open source the agent tools we use on our own work every day.

## Free tools

- **[your-steps](https://github.com/agnostify/your-steps)**: every step your AI agents need you to do, in one pinned T3 Code thread. Type "done 3" and the agent that asked picks its work back up. It works with Claude Code and Codex.
- **[Context Pill](https://github.com/agnostify/context-pill)**: a daily feed of AI releases, tools and techniques for coding agents. Each item says how it was checked, and every source has a public trust score. Live at [contextpill.com](https://contextpill.com).
- **[t3-mods](https://github.com/agnostify/t3-mods)**: looks and moods for T3 Code, including Cube City, where little cubes in the corners of the chat cheer, sulk and jump when you click them.
- **[agent-screens](https://github.com/agnostify/agent-screens)**: a macOS menu bar dashboard for watching AI agents work inside cua sandboxes.
